# Product Overview

## AI Study Assistant

An AI-powered study platform that transforms uploaded study materials (PDFs, images) into interactive learning tools including summaries, quizzes, and flashcards.

### Core Value Proposition
- Upload study materials in any format (PDF, images)
- AI generates summaries, quizzes, and flashcards automatically
- Cloud storage for accessing materials anywhere
- Progress tracking and exam readiness metrics

### Target Users
Students across all subjects who need to:
- Prepare for exams efficiently
- Summarize long reading assignments
- Create practice materials for group study
- Track their learning progress

### Key Features
1. **File Upload & Processing**: PDF and image support with text extraction
2. **AI-Generated Content**: Summaries, multiple-choice quizzes, Q&A flashcards
3. **Study Tools**: Interactive quiz interface, flashcard review system
4. **Library Management**: Organized view of all uploaded materials and generated content
5. **Progress Tracking**: Exam readiness metrics and study session history
6. **Authentication**: Email/password and Google OAuth support

### Pricing Tiers
- **Free**: 5 uploads/month, basic features
- **Student** ($8/month): Unlimited uploads, full features
- **Team** ($18/month): Shared study spaces, group features
